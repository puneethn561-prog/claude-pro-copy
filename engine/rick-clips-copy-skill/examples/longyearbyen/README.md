# Example: The Town Where You're Not Allowed to Die (Longyearbyen)
46 s reel, am_fenrir x1.12, 15 lines / 17 shots. Drop `script.json` and `src/shots.js` into a project made with
`new_video.sh tall-tale longyearbyen`, then run voice.py, words.py, capture check/sheet/cues, mix.py, video.
Sets built in code: snowy town on stilts, bedroom, hospital, cemetery with rising coffins, permafrost cutaway,
1998 lab, sunset runway with plane. Shows: wide crane opener, whip pans with smear, push-ins on speakers,
punch-ins on key words, stamps (DYING = ILLEGAL? / ILLEGAL crossed out / MYTH), anti-whiteout lighting.
